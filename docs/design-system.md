# スマホ小銭研究所 デザインシステム v42.3.1

このドキュメントは、ページ追加時にデザインが散らからないようにするための基準です。

## 目的

スマホ小銭研究所は、派手に煽る比較サイトではなく、条件・対象外・反映時期を落ち着いて確認できるサイトとして見せます。

目指す印象：

- シンプル
- スタイリッシュ
- 信頼感がある
- 認知負荷が低い
- PR/広告感を隠さず、でも押し売りに見せない
- 金融・通信・ポイ活を扱っても怪しく見えない

## ブランドカラー

新規ページでは、原則として以下の色を基調にします。

| 役割 | 推奨値 | 用途 |
|---|---:|---|
| Ink | `#10241d` | 本文・見出しの基本色 |
| Muted Ink | `#5d7168` | 補足文・説明文 |
| Primary Green | `#0f7a55` | 主要CTA・重要ラベル |
| Deep Green | `#0b3024` | 強い見出し・濃いアクセント |
| Mint BG | `#f4fbf7` | ページ背景 |
| Mint Soft | `#ecfdf5` | 薄いカード背景・補助エリア |
| Gold | `#c9962e` | 特典・注意を上品に強調 |
| Border Green | `rgba(15,122,85,.18)` | カード罫線 |
| Shadow Green | `rgba(11,48,36,.08)` | カード影 |

### 避ける色

- 原色の赤・青・黄色を広範囲に使わない
- 蛍光色を使わない
- CTAごとに違う色を使わない
- 1ページ内でアクセントカラーを増やしすぎない

赤系は、対象外・注意・エラーなど本当に必要な時だけ控えめに使います。

## フォント

新規ページの基本フォント：

```css
font-family: "Noto Sans JP", -apple-system, BlinkMacSystemFont, "Hiragino Sans", "Yu Gothic", sans-serif;
```

方針は「大きく目立たせる」ではなく、**金融・通信・条件確認に耐える落ち着いた読みやすさ**です。
丸すぎるフォント、太すぎる見出し、巨大な文字で押すデザインには寄せません。

既存ページにシステムフォント指定が残っていても、今すぐ全面修正はしません。新規ページと大きく触るページから上記へ寄せます。

## タイポグラフィ

### 基本思想

- 文字を大きくして初心者感を出さない
- 見出しは短く、密度は高く、余白で読ませる
- 太字を乱用しない。強調は「サイズ」より「配置・余白・言葉」で行う
- 本文は読みやすく、カード内テキストは詰め込みすぎない
- 英字ラベルは装飾。SEO見出しや本文の代わりにしない

### 推奨スケール

新規ページでは、以下の範囲を目安にします。極端に大きい文字は避けます。

| 要素 | 推奨サイズ | weight | line-height | 用途 |
|---|---:|---:|---:|---|
| body | `15.5px〜16px` | 400〜500 | `1.75〜1.9` | 基本文 |
| lead | `1.02rem〜1.12rem` | 500〜600 | `1.75〜1.9` | ファーストビュー補足 |
| h1 | `clamp(1.65rem, 3.8vw, 2.35rem)` | 750〜850 | `1.16〜1.24` | ページ主見出し |
| h2 | `clamp(1.25rem, 2.6vw, 1.65rem)` | 750〜850 | `1.25〜1.35` | セクション見出し |
| h3/card title | `1.02rem〜1.16rem` | 700〜800 | `1.35〜1.5` | カード内見出し |
| small/label | `.72rem〜.82rem` | 700〜800 | `1.2〜1.4` | ラベル・補足 |

### 避ける表現

- `font-size: 3rem` 以上の大見出しを安易に使う
- `font-weight: 900` を見出し・カード・本文で多用する
- 全体を丸ゴシック風、ポップ体風に見せる
- CTAやカード内で太字を連発する
- 1カード内に見出し・強調・ラベルを詰め込みすぎる
- 行間が狭く、広告LPのように圧迫感がある組み方にする

### 見出しルール

| 要素 | 方針 |
|---|---|
| h1 | 太めだが巨大にしない。短く、1画面で意味が伝わる |
| h2 | セクションの判断軸が分かる日本語にする |
| h3 | カードの結論を一言で示す |
| 本文 | 長文より短い説明とカードで分ける |
| 補足 | muted色で軽く、本文より弱く |
| 英字ラベル | 小さく使う。SEO見出しの代わりにしない |

H2/H3は `POINT` `MEMO` だけにせず、検索意図や読者の判断に関係する日本語を入れます。

### 新規ページの基準CSS例

```css
body{
  font-family:"Noto Sans JP",-apple-system,BlinkMacSystemFont,"Hiragino Sans","Yu Gothic",sans-serif;
  font-size:16px;
  line-height:1.8;
  color:#10241d;
  letter-spacing:-.01em;
}

h1{
  font-size:clamp(1.65rem,3.8vw,2.35rem);
  line-height:1.2;
  letter-spacing:-.055em;
  font-weight:800;
}

h2{
  font-size:clamp(1.25rem,2.6vw,1.65rem);
  line-height:1.32;
  letter-spacing:-.04em;
  font-weight:800;
}

.lead{
  font-size:clamp(1.02rem,2.2vw,1.12rem);
  line-height:1.85;
  font-weight:500;
  color:#5d7168;
}
```

## レイアウト

新規ページは以下を基本にします。

1. ファーストビュー
2. 主要な判断カード
3. 条件チェック
4. 対象外・注意点
5. 公式/ASPリンクCTA
6. 関連ページ
7. PR・最終確認メモ

## コンポーネント方針

### CTA

- CTAは原則 Primary Green
- 1画面内に主CTAを増やしすぎない
- 「公式で確認する」「条件を確認して申し込む」など行動が分かる文言にする
- PR/アフィリエイト導線は隠さない

### カード

- 角丸はやや大きめ。ただし丸すぎるポップ表現にはしない
- 影は薄く
- 枠線は薄いグリーン
- 1カード1役割
- カードを増やして一覧を重くしない

### ラベル

- 「おすすめ」「比較」「条件」「注意」など意味が分かる言葉を使う
- 「準備中」「一部公開」「強化中」「公開中」は表側に出さない

## ページ種別ごとの基準

### トップページ

- カテゴリを増やしすぎない
- 未完成カテゴリを主役にしない
- 1画面で「何のサイトか」が分かるようにする

### カテゴリ一覧ページ

- 最初に見せる候補は3件まで
- その他はコンパクトリスト
- 読者に選ばせたい順番を明確にする

### 個別案件ページ

- まず「向いている人 / 向かない人」を出す
- 条件・対象外・付与時期を確認
- CTAは確認後に出す
- ASPリンク差し替えがしやすい構成にする

### 口座・証券ページ

- 審査中/未提携の間は広告リンクを無理に置かない
- 「準備中」ではなく「条件確認メモ」として成立させる
- 承認後にCTAだけ差し替えられる構成にする

## CSS運用ルール

- 新規ページでは v36 系CSS/JSを使わない
- 既存の v36 系CSS/JSは互換用として残す
- 新規ページは `kozeni-brand.v1.css` / `kozeni-nav.v1.css` / `kozeni-return.v1.css` を基本にする
- インラインCSSは新規ページで増やさない
- 既存ページのインラインCSS撤去はカテゴリ単位で段階的に行う
- 色・余白・フォントはこのドキュメントの基調に寄せる

## やらないこと

- ページごとに違う雰囲気のデザインを作らない
- 案件ごとにCTA色を変えない
- 情報量を増やしすぎて比較サイト風にしすぎない
- 金額だけで煽らない
- 「作りかけ」に見える文言を表に出さない
