# スマホ小銭研究所 デザインシステム v45.0

このドキュメントは、ページ追加時にデザインが散らからないための視覚方針です。実値のSSOTは`assets/kozeni-tokens.v1.css`、技術的な運用ルールは`docs/design-tokens.md`にあります。

## 目指す印象

- シンプルで落ち着いている
- 条件・対象外・反映時期を読み取りやすい
- PRや広告であることを隠さない
- 金融・通信・ポイ活を扱っても怪しく見えない
- 大きな文字や派手な色ではなく、構造と余白で判断しやすくする

## 色

ページCSSへ色コードを複製せず、共通トークンを参照します。

| 役割 | トークン | 現在値 |
|---|---|---:|
| 基本文字 | `--kozeni-ink` | `#222831` |
| 補足文字 | `--kozeni-muted` | `#62736b` |
| ブランド | `--kozeni-green` | `#228c62` |
| 主要アクセント | `--kozeni-deep` | `#0f7a55` |
| ミント | `--kozeni-mint` | `#4dbd8c` |
| 薄い背景 | `--kozeni-pale` | `#e9f5ef` |
| ページ背景 | `--kozeni-bg` | `#f8fffb` |
| 注意補助 | `--kozeni-gold` | `#f2c94c` |

ページ固有の色は、そのページだけに意味がある場合に限ってカテゴリCSSへ残せます。

### 避けること

- CTAごとに色を変える
- 原色の赤・青・黄色を広範囲に使う
- 同じ色を別名の16進数やRGB値で複製する
- データJSONやHTMLへ色を持たせる

## フォント

基本フォントは次の共通トークンだけを使用します。

```css
font-family: var(--kozeni-font-sans);
```

方針は「大きく目立たせる」ではなく、金融・通信・条件確認に耐える落ち着いた読みやすさです。

## タイポグラフィ

| 要素 | 目安 | 方針 |
|---|---:|---|
| body | `15.5px〜16px` | 行間`1.75〜1.9` |
| lead | `1.02rem〜1.12rem` | 本文より少し強い |
| h1 | `clamp(1.65rem,3.8vw,2.35rem)` | 巨大にしない |
| h2 | `clamp(1.25rem,2.6vw,1.65rem)` | 判断軸を日本語で示す |
| h3 | `1.02rem〜1.16rem` | カードの結論を示す |
| label | `.72rem〜.82rem` | 装飾であり見出しの代用にしない |

`font-weight:900`以上や`3rem`を超える見出しを安易に増やしません。既存ページを大きく変更する場合は、内容を失わず段階的に整えます。

## レイアウト

基本順序は次です。

1. ファーストビュー
2. 主要な判断カード
3. 条件チェック
4. 対象外・注意点
5. 公式／ASPリンクCTA
6. 関連ページ
7. PR・最終確認メモ

## コンポーネント

### CTA

- 主要CTAはブランドグリーン系に統一する
- 行動が分かる文言にする
- PR・アフィリエイト導線を明示する
- 1画面へ主CTAを増やしすぎない

### カード

- 1カード1役割
- 薄い影とグリーン系の罫線を使う
- 角丸は`--kozeni-radius-*`から選ぶ
- 一覧を増やしすぎて比較サイト風にしない

### ラベル

「おすすめ」「比較」「条件」「注意」など意味の分かる日本語を使います。「準備中」「公開中」など内部状態は表示しません。

## CSS運用

- 読み込みの先頭に`kozeni-tokens.v1.css`を置く
- 共通色・フォント・角丸・影はトークンを使う
- カテゴリCSSはページ固有の構造と別名変数だけを持つ
- インラインCSSとインライン実行JavaScriptを追加しない
- 旧`v36`および旧home/menu資産を再追加しない
- ページ固有レイアウトを無理に共通化しない

検証は次の1コマンドだけで行います。

```bash
python3 tools/verify_site.py
```
