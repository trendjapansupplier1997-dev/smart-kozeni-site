コード入力前に見ること

  • 招待リンクの有効期限
  • 新規登録条件

  • 報酬付与の条件と反映タイミング
  • 対象外条件の記載

使い方の流れ

  1. 招待リンクを開く

    ブラウザではなくアプリ側に遷移する場合があります。開いた先の表示を確認します。

  2. 条件画面を読む

    最大表示・達成条件・期限・対象者・対象外条件を確認します。

  3. 必要ならコードを控える

    リンクが開けない、コード入力欄が出るなどの場合に、上のコードを使う前提で確認します。

  4. 登録後の画面を保存

    条件達成や報酬反映の確認用に、招待画面・ミッション画面をスクショしておきます。
