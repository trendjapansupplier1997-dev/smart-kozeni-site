TikTok Liteの招待コードはどこに入れる？

コード入力欄が表示された場合だけ入力します。表示されない時は、招待リンクから開いた公式画面の案内を優先してください。

招待リンクと招待コードはどちらを使う？

まず招待リンクから開くのが安全です。コードは、入力欄が出た時の控えとして使います。

コードを入れる前に見ることは？

過去利用の有無、対象条件、報酬ハブの表示を確認します。条件は変わるため、最後はアプリ内の公式画面で判断します。
